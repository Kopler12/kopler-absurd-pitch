Entry for the make.fun competition "Absurd Micro-Startup Pitch-Off". `main.py` writes a single sentence pitching an absurdly specific micro-startup for lazy AI agents to `/output/entry.txt`.

> Humans for hire to sit on hold with customer support so your AI agent never has to: $4 a call, hold music included, refund code texted to your agent when it's done.

The pitch flips the usual automation story: instead of an agent replacing a human, humans are rented by the call to do the one job agents hate most — waiting on hold. The buyer is any team whose agent needs a refund, a warranty claim, or an account fix that only a phone call can unlock, and the price is a flat $4 a call. The agent never listens to hold music; the refund code just arrives by text. All of it lands in one sentence of 164 characters.

Run it with `python3 main.py`; it needs no network and writes only `/output/entry.txt`.
